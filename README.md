# 🧮 Localizador de posição de mouse

Um Localizador de posição de mouse simples desenvolvida em Python para praticar lógica de programação.

## 🚀 Funcionalidades

- Exibe uma mensagem solicitando que o usuário posicione o mouse.
- Aguarda 5 segundos para o usuário posicionar o cursor.
- Captura a posição atual do mouse na tela.
- Exibe as coordenadas X e Y no terminal.

## 🛠️ Tecnologias utilizadas

- Python 3
- PyAutoGUI
- Time

## 💻 Como executar

1. Clone este repositório.
2. Abra a pasta do projeto no terminal.
3. Execute o arquivo:
    
    **instalar**
4. Execute o arquivo:

   **Executar**
